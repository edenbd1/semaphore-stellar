# semaphore-stellar-verifier

Groth16/BN254 verifier for Semaphore v4 proofs on Soroban/Stellar. Because Soroban's BN254 is
EVM-compatible, proofs produced with Ethereum's Semaphore trusted-setup ceremony verify
unchanged. Part of [semaphore-stellar](https://github.com/edenbd1/semaphore-stellar).

MIT. Prototype, unaudited, testnet only.
