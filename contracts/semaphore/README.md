# semaphore-stellar

A faithful port of Semaphore v4 to Soroban/Stellar: anonymous group membership, an epoch-scoped
nullifier, and an arbitrary signal, verified with Groth16/BN254 against Ethereum's Semaphore
ceremony. See [semaphore-stellar](https://github.com/edenbd1/semaphore-stellar).

MIT. Prototype, unaudited, testnet only.
